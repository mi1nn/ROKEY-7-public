## 3. 일정표 쓰는 법

[schedule-timeline.csv](schedule-timeline.csv) 는 기존 구글 시트 "Time Line." 탭과 같은 열 순서다: 카테고리 / 항목 / 구분 / 세부항목 / 비고 / 담당자 / 진행 상황, 그 뒤에 날짜별 오전·오후·저녁 칸.

- 구글 시트에서 `파일 → 가져오기 → 업로드` 로 CSV 를 열고, `■` 칸에 색을 칠한다.
- `비고` 의 `CP` 는 핵심 경로 작업이다. "CRITICAL PATH ITEM" 탭으로 옮길 때 이 줄만 고르면 된다.
- `진행 상황` 은 0(시작 전) ~ 1(완료)이다. 매일 저녁 담당자가 고치고, PM 이 막힌 것을 정리한다.
- `담당자` 가 `전원` 인 줄은 7명 모두다. 사람별로 보려면 이 열로 필터한다.
- 일정을 바꿀 때는 이 CSV 를 고치는 PR 을 연다. 시트와 저장소가 어긋나면 저장소가 기준이다.
