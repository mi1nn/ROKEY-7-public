- 5절 ping 은 이 자리가 TB-5 담당 PC 에서 직접 쟀다 [측정]. 원문: [field-2026-10-13-pi-settings.log](field-2026-10-13-pi-settings.log). 주소는 자리표시로 가렸다.

## 3. 자동 업데이트 끄기 (재부팅해도 유지)

> [!WARNING]
> 원문 미확인 (전달: 작전 자리, 2026-10-13):
> - 두 Pi 모두 같은 절차로 바꿨다.
>   1. `~/backup-20261013/20auto-upgrades` 로 백업.
>   2. `/etc/apt/apt.conf.d/20auto-upgrades` 를 `APT::Periodic::Update-Package-Lists "0"`, `APT::Periodic::Unattended-Upgrade "0"` 으로 바꿈.
>   3. `apt-daily.timer`, `apt-daily-upgrade.timer`, `unattended-upgrades` 를 `disable --now`.
> - 바꾼 뒤 확인 (14:29): 파일 sha256 `77d2fc9523114ea10df5e96a4b0859ef390a01e510c8b1a5f0bd5b2de7b11966` (두 Pi 같음). `apt-config` 로 두 값 모두 `"0"`. `is-enabled` 셋 다 `disabled`. apt 타이머 0개.
> - 바꾸기 전 상태: 10-08 17:34 에 TB-5 에서 unattended-upgrade 가 실행된 기록이 있다. 로그인 화면에 "1 updates could not be installed automatically" 가 떴다.

- 바꾸기 전 해시: 사용자 화면에 없었다. 백업 파일의 해시로 남겨야 하지만 아직 없다 [미확인]. AGENTS.md 6절의 "바꾸기 전 해시가 백업과 같은지 확인" 단계는 이 기록으로 증명되지 않는다.
- 되돌리기: 백업 파일을 `/etc/apt/apt.conf.d/20auto-upgrades` 로 다시 복사한다. 그 뒤 세 단위를 `enable --now` 한다.
- 이유 [추정]: 시연 중에 자동 업데이트가 돌면 CPU·디스크·네트워크를 쓰고, 패키지가 바뀔 수 있다.

## 5. 바꾼 뒤 ping 비교 [측정]

TB-5 담당 PC 에서 `ping -c 50 -i 0.2` 로 쟀다. 이 PC 의 무선 절전 설정은 바꾸지 않았다. NetworkManager 전역값이 켬이라 PC 쪽 절전은 켜져 있을 것으로 본다 [추정, #171 8절].

| 시각 | 대상 | 손실 | 최소 / 평균 / 최대 / 편차 (ms) |
| --- | --- | --- | --- |
| 12:47 (전) | TB-5 | 0/50 | 2.069 / 11.714 / 52.309 / 9.545 |
| 12:47 (전) | TB-6 | 0/50 | 3.226 / 35.053 / 404.210 / 68.987 |
| 14:30 (뒤 1회) | TB-5 | 1/50 | 1.743 / 10.006 / 202.605 / 27.906 |
| 14:30 (뒤 1회) | TB-6 | 0/50 | 1.477 / 4.389 / 42.852 / 6.070 |
| 14:31 (뒤 2회) | TB-5 | 1/50 | 2.148 / 6.718 / 21.196 / 3.428 |
| 14:31 (뒤 2회) | TB-6 | 0/50 | 1.430 / 5.016 / 29.568 / 4.728 |

- TB-6 평균 지연은 35.1 ms 에서 4.4–5.0 ms 로 줄었다. 최대는 404 ms 에서 30–43 ms 로 줄었다.
- TB-5 는 평균이 11.7 ms 에서 6.7–10.0 ms 다. 두 회차 모두 손실이 1개씩 있었고, 1회차 최대는 203 ms 였다.
- **조건이 같지 않다.** 12:47 에는 TB-6 에서 SLAM·Nav2·rviz2 가 돌고 언도킹 상태였다(#171 7절). 14:30 에는 두 카메라가 도킹 절전으로 꺼져 있었다(4절). 그러므로 이 차이를 무선 절전 끄기의 효과로만 볼 수 없다. 표본도 회차당 50개뿐이다.
- 같은 조건(언도킹, 카메라·Nav2 동작)에서 다시 재야 효과를 가를 수 있다. 그 측정은 하지 않았다 [미측정].

## 후속

- 3절 바꾸기 전 해시: 백업 파일 `~/backup-20261013/20auto-upgrades` 의 sha256 을 Pi 에서 읽어 덧붙인다.
- `config/robots/` 반영: AGENTS.md 6절은 로봇 설정을 바꾸면 `config/robots/` 도 같이 고치라고 한다. 이 PR 은 기록만 하고, 그 파일은 기반 레인이 판단한다.
- 무선 절전은 재부팅하면 다시 켜진다. 현장 런북의 아침 점검에 `iw dev wlan0 get power_save` 를 넣을지는 실기·배포 레인 후속이다.
