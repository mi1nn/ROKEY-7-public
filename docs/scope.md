# 재난 수색 파이널의 범위와 인수 조건

AMR 2대가 변화하는 재난 모사 환경에서 협업 수색하고, 발견한 대상에 접근한 결과와 위치·현장 정보를 관제에 보고한다. 이 문서는 구현할 범위를 정한다. 디렉터리·배포 구조·알고리즘 선택은 계획 PR 2, 메시지·상태 전이·시험 수치의 상세 계약은 계획 PR 3에서 검토한다.

## 사용자 요구

`[사용자 요구]` 아래 근거는 2026-10-07 프로젝트 시작 대화의 사용자 발언이다. 원본 저장소의 예전 주제·장비 배치·일정으로 덮어쓰지 않는다. 공개된 대화 링크는 이 PR에 포함하지 않으며, 사용자가 이 기록의 정확성을 검토한다. 직접 발언과 작성자의 설계 해석을 구별한다.

## 완료 범위와 제외 범위

`발견`, `위치 확인`, `접근 완료`, `보고 완료`를 구분하는 것을 제안한다. 로봇이 사람을 실제 이송한 것처럼 `구조 완료`라고 표시하지 않는다. 보고의 “상태”는 관측 시각, 확인 여부, 접근 결과처럼 시스템이 관측한 내용으로 정의한다. 건강·부상·생존 상태를 확정하는 기능은 넣지 않는다.

| 포함할 기능 | 이번 범위에서 제외할 기능 |
| --- | --- |
| 두 로봇의 역할 분담과 발견 정보 공유 | 사람을 들어 올리거나 이송하는 물리적 구조 |
| 수색 중 지도 갱신과 로봇 위치 추정 | 안전지대까지 사람을 이동 안내하는 기능 |
| 통로 변화에 따른 경로 재검토 | 구호물품 **전달 장치**(매니퓰레이션)와 사람 안내. 구급상자를 **싣고 이동**하는 것은 RQ-08 로 포함(탑재 방식은 Q-16) |
| 사람 또는 합의한 시연 대상의 탐지·위치 추정 | RC카 추종을 파이널의 목표로 유지하는 것 |
| 접근 가능한 지점에서 정지하고 결과 보고 | 원본 과제·미니 산출물 전체의 보존·실행 호환 |
| 접근 불가, 위치 불확실, 통신 이상에 대한 명시적 처리 | 센서로 확인하지 않은 지진·붕괴·부상 상태의 자동 확정 |

위 제외 항목 중 사람 이송·안내·물품 전달은 RQ-04의 범위를 정리한 것이다. 상태 이름과 보고 세부 필드는 설계 제안이며 계획 PR 3에서 확정한다.

## 첫 통합 시나리오

RQ-08(2026-10-08) 이전의 대칭 A·B 시나리오는 아래 표의 「이전」 열에 남긴다. 현재 기준은 [BRD v0.1](brd-v0.1.md) 의 흐름이고, TB1·TB2 는 역할 표기다. 역할은 배포 프로파일의 입력이며 코드 상수로 고정하지 않는다(역할을 바꿔 넣으면 두 로봇이 뒤집혀 동작해야 한다).

| 단계 | 현재(BRD v0.1) | 이전(대칭 A·B, 2026-10-07) |
| --- | --- | --- |
| 1 | 고정 카메라 A 가 영상 흔들림·가려짐으로 지진 징후를 감지하면 시스템이 재난 모드로 바뀌고 TB1 에 출발을 지시한다(판정 조건·해제는 Q-11) | A·B 가 배정받은 구역을 수색한다 |
| 2 | TB1 이 이동하며 지도를 실시간 갱신한다. 기준 지도 대비 장애물 변화를 관제가 표시한다(Q-09) | 지도 갱신·위치 추정을 관제에서 확인 |
| 3 | TB1 이 사람(인형)을 탐지한다. 대상 ID, 관측 시각, 위치·좌표 기준, 근거를 DB 에 저장하고 **저장 확인 뒤** TB2 에 통지한다 | A 가 대상을 발견하고 전달한다 |
| 4 | 협업 제어가 TB2 에 접근 임무를 배정한다. TB2 는 구급상자를 싣고 대기하다 출동해 요구조자 인근의 도달 가능한 지점에서 정지한다. 경로가 없으면 접근 불가 사유를 보고하고 발견 기록은 유지한다 | B 에 확인·접근 임무 배정, 장애물 추가 시 우회·접근 불가 |
| 5 | TB1 은 수색을 이어간다(접근 중 다른 로봇의 정책은 협업·관제가 명시) | B 재확인·정지, A 수색 지속 |
| 6 | 출구 카메라 B 가 구조된 사람(인형)을 탐지해 인원을 집계하고 DB·화면에 반영한다(중복 집계 금지, 식별은 Q-13) | — |
| 7 | TB1 이 해당 지점으로 다시 이동해 카메라·LiDAR 로 재탐지한다. 대상 지점을 실제로 관측했고 사람·장애물 판정이 없고 출구 카운트가 확인된 경우에만 "구출 완료" 를 표시하며, 아니면 "재확인 필요" 를 유지한다(Q-10). 부재 증거만으로 완료를 표시하지 않는다 | — |
| 8 | 관제에 대상 위치, 관측 근거, 담당 로봇, 발견·확인·접근·출구·재확인 시각이 같은 사건으로 기록된다 | 동일 |

대상 ID·사진·관측 시각은 보고 계약(C-05)의 필드이고, 고정 카메라·모드·사건 상태의 추가 계약은 [작업 묶음](work-bundles.md) 4절에서 확정한다. 관측 위치를 보냈다는 사실만으로 지도 정렬이나 대상 동일성이 검증된 것으로 보지 않는다.

PR 초안 작성과 검토는 병렬로 진행하며 앞 PR의 머지를 기다리지 않는다. 의존하는 PR은 상위 브랜치 위에 쌓아 diff와 기준 SHA를 구분한다. Codex는 피드백을 일괄 반영한 뒤 PR별 최종 검토를 수행하고 Cursor에 인계한다. Claude는 로직·계획 검토, Cursor는 검증·수정·머지를 맡는다. main 머지는 의존 순서를 지킨다. 수정 후 재검토·하위 PR 정리·인계 조건은 [역할별 검토 지침](review-workflow.md)에 둔다. 교차 검증과 실제 두 로봇·네 PC의 인수 시험은 별개다.
