# 재난 수색 파이널의 범위와 인수 조건

AMR 2대가 변화하는 재난 모사 환경에서 협업 수색하고, 발견한 대상에 접근한 결과와 위치·현장 정보를 관제에 보고한다. 이 문서는 구현할 범위를 정한다. 디렉터리·배포 구조·알고리즘 선택은 계획 PR 2, 메시지·상태 전이·시험 수치의 상세 계약은 계획 PR 3에서 검토한다.

아래 근거는 2026-10-07 프로젝트 시작 대화의 사용자 발언이다. 원본 저장소의 예전 주제·장비 배치·일정으로 덮어쓰지 않는다. 공개된 대화 링크는 이 PR에 포함하지 않으며, 사용자가 이 기록의 정확성을 검토한다.

## 완료 범위와 제외 범위

`발견`, `위치 확인`, `접근 완료`, `보고 완료`를 구분하는 것을 제안한다. 로봇이 사람을 실제 이송한 것처럼 `구조 완료`라고 표시하지 않는다. 보고의 “상태”는 관측 시각, 확인 여부, 접근 결과처럼 시스템이 관측한 내용으로 정의한다. 건강·부상·생존 상태를 확정하는 기능은 넣지 않는다.

| 포함할 기능 | 이번 범위에서 제외할 기능 |
| --- | --- |
| 두 로봇의 역할 분담과 발견 정보 공유 | 사람을 들어 올리거나 이송하는 물리적 구조 |
| 수색 중 지도 갱신과 로봇 위치 추정 | 안전지대까지 사람을 이동 안내하는 기능 |
| 통로 변화에 따른 경로 재검토 | 구호물품 운반·전달 장치 |
| 사람 또는 합의한 시연 대상의 탐지·위치 추정 | RC카 추종을 파이널의 목표로 유지하는 것 |
| 접근 가능한 지점에서 정지하고 결과 보고 | 원본 과제·미니 산출물 전체의 보존·실행 호환 |
| 접근 불가, 위치 불확실, 통신 이상에 대한 명시적 처리 | 센서로 확인하지 않은 지진·붕괴·부상 상태의 자동 확정 |

위 제외 항목 중 사람 이송·안내·물품 전달은 RQ-04의 범위를 정리한 것이다. 상태 이름과 보고 세부 필드는 설계 제안이며 계획 PR 3에서 확정한다.

## 첫 통합 시나리오

아래는 RQ-03~06을 검증하기 위한 제안이다. A·B는 실제 장비 번호가 아닌 역할 표기다. 항상 A만 탐지하고 B만 접근하게 고정하는 배정 알고리즘을 뜻하지 않는다.

1. A와 B가 배정받은 구역을 수색한다. 지도 갱신과 위치 추정 상태를 관제에서 확인한다.
2. A가 대상을 발견한다. 대상 식별자, 관측 시각, 위치와 좌표 기준, 확인 근거를 전달한다.
3. 협업 제어가 B에 확인·접근 임무를 배정한다. B는 A의 좌표를 자신의 주행 좌표로 해석할 수 있어야 한다.
4. B의 이동 경로에 장애물을 추가한다. B는 경로를 재검토하고 우회하거나 접근 불가로 처리한다.
5. B는 대상 위치를 재확인하고 접근 지점에서 정지한다. A는 별도 수색을 이어간다.
6. 관제에 대상 위치, 관측 근거, 담당 로봇, 발견·확인 시각, 접근 결과가 같은 사건으로 기록된다.

대상 ID·사진·관측 시각 등은 보고 계약 후보이며 메시지 필드를 아직 정하지 않았다. 관측 위치를 보냈다는 사실만으로 지도 정렬이나 대상 동일성이 검증된 것으로 보지 않는다.

## 이 PR에서 검토할 것

- RQ-01~07이 사용자 요구를 정확하게 옮겼는가.
- 인수 시나리오가 두 로봇의 실제 협업과 환경 변화 대응을 포함하는가.
