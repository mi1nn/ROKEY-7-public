# 재난 수색 파이널의 범위와 인수 조건

AMR 2대가 변화하는 재난 모사 환경에서 협업 수색하고, 발견한 대상에 접근한 결과와 위치·현장 정보를 관제에 보고한다. 이 문서는 구현할 범위를 정한다. 디렉터리·배포 구조·알고리즘 선택은 계획 PR 2, 메시지·상태 전이·시험 수치의 상세 계약은 계획 PR 3에서 검토한다.

## 완료 범위와 제외 범위

`발견`, `위치 확인`, `접근 완료`, `보고 완료`를 구분하는 것을 제안한다. 로봇이 사람을 실제 이송한 것처럼 `구조 완료`라고 표시하지 않는다. 보고의 “상태”는 관측 시각, 확인 여부, 접근 결과처럼 시스템이 관측한 내용으로 정의한다. 건강·부상·생존 상태를 확정하는 기능은 넣지 않는다.

| 포함할 기능 | 이번 범위에서 제외할 기능 |
| --- | --- |
| 두 로봇의 역할 분담과 발견 정보 공유 | 사람을 들어 올리거나 이송하는 물리적 구조 |
| 수색 중 지도 갱신과 로봇 위치 추정 | 안전지대까지 사람을 이동 안내하는 기능 |
| 통로 변화에 따른 경로 재검토 | 구호물품 **전달 장치**(매니퓰레이션)와 사람 안내. 구급상자를 **싣고 이동**하는 것은 RQ-08 로 포함(탑재 방식은 Q-16) |
| 사람 또는 합의한 시연 대상의 탐지·위치 추정 | RC카 추종을 파이널의 목표로 유지하는 것 |
| 접근 가능한 지점에서 정지하고 결과 보고 | 원본 과제·미니 산출물 전체의 보존·실행 호환 |
| 접근 불가, 위치 불확실, 통신 이상에 대한 명시적 처리 | 센서로 확인하지 않은 지진·붕괴·부상 상태의 자동 확정 |

위 제외 항목 중 사람 이송·안내·물품 전달은 RQ-04의 범위를 정리한 것이다. 상태 이름과 보고 세부 필드는 설계 제안이며 계획 PR 3에서 확정한다.

RQ-10에 따라 AMR2가 요구조자 위치로 자동 출동하고 구조대원이 뒤따른다. 요구조자 인형을 로봇이 안전지대로 이송하는 기능은 포함하지 않는다. RQ-11의 AMR1 관제 버튼 출동과 Q-10의 이중 확인 완료 판정은 유지한다. 두 로봇은 같은 필드에서 이동한다(RQ-12). 현재 흐름은 아래 표와 [BRD v0.2](brd-v0.2.md)·[SRD v0.2](srd-v0.2.md)를 따른다. 기존 실행 계약 C-12·SDD 11쪽의 승인 후 카메라 추종은 과거 요구이며, 자동 출동 구현으로 재해석하지 않는다.

## 첫 통합 시나리오

RQ-08 이전 대칭 A·B 흐름은 「이전」 열에 남긴다. 「현재」 열은 웹캠 1대 결정, AMR1 관제 버튼 출동(RQ-11), 2026-10-12 AMR2 자동 출동·구조대원 후행·동일 필드 요구(RQ-10/12)를 반영한다. [BRD Part I](brd-part1-v0.1.md)와 [BRD v0.1](brd-v0.1.md)은 팀 원문·과거 기록이며 변경된 출동/동행 요구는 이 문서가 우선한다. TB1(AMR1)·TB2(AMR2)는 배포 프로파일의 역할 표기다.

| 단계 | 현재(웹캠 1대·동일 필드, 2026-10-12) | 이전(대칭 A·B, 2026-10-07) |
| --- | --- | --- |
| 1 | 고정 웹캠의 유효한 지진 징후(`DISASTER_SIGN`)를 검증해 재난 모드와 근거를 관제에 표시·저장한다(Q-11). 운영자의 AMR1 출동 버튼(`START_SEARCH`) 명령 뒤에만 지도 준비·최초 정찰을 요청한다(RQ-11). AMR2는 인형 발견 전 대기한다. 가림·끊김은 UNKNOWN이며 같은 이벤트로 중복 출동하지 않는다 | A·B가 배정받은 구역을 수색한다 |
| 2 | TB1 이 이동하며 지도를 실시간 갱신한다. 기준 지도 대비 장애물 변화를 관제가 표시한다(Q-09) | 지도 갱신·위치 추정을 관제에서 확인 |
| 3 | AMR1이 인형을 탐지하고 대상 ID·관측 시각·유효한 위치·지도 기준·근거를 DB에 저장한다. **저장 확인 뒤** 관제에 표시하고 확정 대상을 AMR2 자동 출동 입력으로 전달한다. 좌표 불확실·미확정 후보는 발견 기록만 남기고 이동 목표로 쓰지 않는다 | A가 대상을 발견하고 전달한다 |
| 4 | AMR2는 구급상자를 싣고 대기하다 AMR1의 유효한 인형 발견 좌표를 받아 별도 운영자 출동 승인 없이 자동으로 접근한다(RQ-10). 구조대원이 AMR2를 뒤따르며 AMR2는 사람의 다리를 추종하지 않는다. 구간별 ‘계속’ 승인은 없다. 요구조자 인근 도달 가능한 지점에서 정지한 뒤 인형을 재탐지한다. 경로 없음·준비/좌표 불확실·통과 근거 부족이면 이동을 보류하거나 중단하고 사유를 보고한다 | B에 확인·접근 임무 배정, 장애물 추가 시 우회·접근 불가 |

PR 초안 작성과 검토는 병렬로 진행하며 앞 PR의 머지를 기다리지 않는다. 의존하는 PR은 상위 브랜치 위에 쌓아 diff와 기준 SHA를 구분한다. Codex는 피드백을 일괄 반영한 뒤 PR별 최종 검토를 수행하고 Cursor에 인계한다. Claude는 로직·계획 검토, Cursor는 검증·수정·머지를 맡는다. main 머지는 의존 순서를 지킨다. 수정 후 재검토·하위 PR 정리·인계 조건은 [역할별 검토 지침](../process/review-workflow.md)에 둔다. 교차 검증과 실제 두 로봇·네 PC의 인수 시험은 별개다.
